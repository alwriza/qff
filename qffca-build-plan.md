# QFFCA 2026 — build plan

Полный план сборки сайта. Документ рассчитан на исполнение агентом: собрать весь сайт целиком, со всеми секциями и страницами. Там, где информации ещё нет, ставить плейсхолдеры вида `[ TBD ]` — не пропускать секцию, не выдумывать данные.

Событие: **Qiskit Fall Fest Central Asia 2026**, Nazarbayev University, Астана. Первый Qiskit Fall Fest в Центральной Азии.

---

## 1. Стек

- **Next.js 15**, App Router, TypeScript, `output: 'export'` (статика)
- **Tailwind CSS v4** — токены через `@theme` в `globals.css`
- **next-intl** — три локали, сегмент `[locale]`
- **next/font/google** — IBM Plex Sans, IBM Plex Sans Condensed, IBM Plex Mono, сабсеты `latin`, `cyrillic`, `cyrillic-ext`
- Анимации — **без библиотек**: CSS-переходы + `IntersectionObserver` + один кастомный хук для декрипшна. Никаких framer-motion, GSAP, three.js.
- Деплой — Vercel

Никаких дополнительных зависимостей без необходимости. Чем меньше поверхность, тем легче сдавать.

| Комбинация | Ratio | Вердикт |
|---|---|---|
| coral на bg | 5.32 | ок для любого текста |
| coral на surface | **3.22** | **только крупный текст ≥24px, никогда body** |
| coral на mint | **1.87** | **запрещено полностью** |
| text на bg | 15.4 | ок |
| mint на bg | 9.94 | ок |
| muted на bg | 8.73 | ок |
| muted на surface | 5.28 | ок |
| muted на surface-2 | ~3.9 | **на surface-2 только `text`** |

### Типографика

- Display: `IBM Plex Sans Condensed`, **italic 700**, uppercase, `clamp(38px, 8vw, 124px)`, `line-height: .90`, `letter-spacing: -.02em`
- H2: тот же стиль, `clamp(30px, 5vw, 64px)`
- Body: `IBM Plex Sans` 300/400, 17px, `line-height: 1.55`
- Utility: `IBM Plex Mono` 400/500, 11–13px, `letter-spacing: .09em`, uppercase — даты, время, лейблы, метки гейтов, счётчик, значения в readout

⚠️ **Проверить первым делом:** казахские глифы `ә ғ қ ң ө ұ ү һ і` в IBM Plex Sans Condensed. Если в Condensed их нет — для локали `kk` заголовки набирать `IBM Plex Sans` Bold Italic, остальные локали не трогать. Проверять рендером, а не предположением.

### Форма

- `border-radius: 0` везде, без исключений
- Теней нет. Разделение — смена тона и хайрлайны 1px
- Контейнер `max-width: 1512px`, паддинг 32px (20px на мобильном)
- **Видимая сетка**: 8 вертикальных линий 1px `--border` с `opacity .13`, `position: fixed`, `pointer-events: none`, скрыты ниже 800px
- **Зерно**: SVG feTurbulence, `opacity .04`, fixed, поверх всего, `pointer-events: none`
- Фото команды и спикеров — квадратные

## 4. Hero

### 4.1 Декрипшн — главный приём

Один механизм, не два. Никаких наложенных ghost-слоёв на разных языках — они конфликтуют с посимвольной расшифровкой и убивают читаемость.

**Как работает `DecryptText`:**

1. Компонент получает финальную строку и раскладывает её на символы.
2. Пока символ не «разрешён», он показывает случайный глиф из шумового набора, меняясь каждые 40–60 мс.
3. Символы разрешаются слева направо волной, но с джиттером ±2 позиции, чтобы фронт не был идеально ровным.
4. Пробелы и переносы строк разрешены сразу — форма заголовка держится с первого кадра, страница не прыгает.
5. Общая длительность — **не более 1400 мс** независимо от длины строки: скорость волны считается от количества символов, а не задаётся константой.

**Шумовой набор — в этом вся идея:**

```
латиница        A–Z
кириллица       А–Я
казахские       Ә Ғ Қ Ң Ө Ұ Ү Һ І
квантовая нотация  |0⟩ |1⟩ ⊗ ⊕ ψ φ θ ħ π √ ∑ ⟨ ⟩
```

Шум сам по себе несёт «три языка + квант», а разрешается в один конкретный язык. Расшифровка = измерение: до него символ во всех состояниях сразу, после — в одном.

**Поведение:**
- На загрузке: задержка 250 мс, затем расшифровка h1 и, со сдвигом 200 мс, подзаголовка
- При смене языка: строка снова уходит в шум и расшифровывается в новый язык
- `prefers-reduced-motion` — финальный текст сразу, без анимации
- В DOM всегда лежит настоящий финальный текст. Шум рисуется в `aria-hidden` слое, доступное дерево не трогается. Это обязательно: иначе скринридер и поисковик увидят мусор
- Декрипшн применяется **только** к h1 и подзаголовку hero. Больше нигде на сайте

## 5. Readout — замена блока статистики

Текущие три большие цифры в ряд выглядят шаблонно. Заменить на **калибровочную таблицу** — по образцу панели свойств процессора в IBM Quantum.

Полноширинная секция на `--surface`. Строки с хайрлайнами, каждая:

```
mono-лейбл слева ────────── тонкая полоса-индикатор ────────── значение справа (крупно, mono)
```

Строки:

| Лейбл | Значение | Полоса |
|---|---|---|
| PARTICIPANTS WORLDWIDE 2025 | 32,000+ | 100% |
| UNIVERSITIES WORLDWIDE 2025 | 150 | 78% |
| IN CENTRAL ASIA | 1ST EVER | 100%, коралловая |
| PROGRAM LENGTH | 5 WEEKS | 62% |
| SEATS | 70–100 | 45% |
| PRICE | FREE | 100% |

Поведение: при попадании в вьюпорт полосы вырастают слева направо (400 мс, ease-out, стагger 60 мс между строками), числа отсчитываются вверх за 700 мс. Один раз, без повтора при обратном скролле. При reduced-motion — сразу финальное состояние.

Коралловый — только на строке «1st ever», это главное утверждение сайта.

Схема работает, но нуждается в подпорках для читаемости.

3. **Предвыбранный первый гейт** — панель деталей не должна открываться пустой.
4. Строку под заголовком: «Читается как квантовая схема — каждая неделя это кубит, каждая сессия гейт, хакатон это измерение».

**Оставить как есть:** переключатель Схема/Список равноправным, автоматический список ниже 800px, клавиатурную навигацию по гейтам, двойные линии от измерений в классический регистр с подписью `certificates`.

**Конвенции рисования — не отступать:**
- время слева направо
- однокубитный гейт — квадрат со стороной ~38–52px, буква внутри
- CNOT — закрашенная точка на контроле, вертикаль, ⊕ на мишени (окружность + крест)
- барьеры — вертикальный пунктир между колонками
- измерение — бокс с дугой и стрелкой прибора
- классический регистр — двойная линия, подпись `c₅`

Источник данных — `config/program.ts`. Схема и список рендерятся из одного массива, не из двух.

## 8. Конфиг события

`config/event.ts` — единственное место, где живут изменяемые поля. Всё, что помечено TBD, меняется одной строкой без правки компонентов.

```ts
export const event = {
  name: "Qiskit Fall Fest Central Asia 2026",
  shortName: "QFFCA 2026",
  university: "Nazarbayev University",
  city: "Astana",
  startDate: null,            // "2026-10-24" — countdown и hero
  endDate: null,
  saturdays: 5,
  seats: { min: 70, max: 100 },
  price: "free",
  registrationUrl: null,      // null → кнопка disabled, "opens soon"
  registrationDeadline: null,
  format: null,               // "in-person" | "hybrid"
  venue: { building: null, room: null, address: null, mapUrl: null },
  contactEmail: null,         // ЛИЧНУЮ ПОЧТУ НЕ СТАВИТЬ
  communityUrl: null,
  socials: { instagram: null, linkedin: null, telegram: null },
  postEvent: { enabled: false },
};
```

Правило рендера: `null` → секция или поле показывает `[ TBD ]` либо скрывается по правилам §7. Сайт обязан собираться и выглядеть законченным при всех `null`.

## 9. Локализация

- Локаль в URL: `/en` (дефолт), `/ru`, `/kk`. Не клиентский переключатель — иначе IBM и LinkedIn заиндексируют случайный язык
- `generateStaticParams` для трёх локалей, `hreflang` на всех
- Переключатель языка сохраняет якорь: `/ru#program` → `/en#program`
- Приоритет заполнения: EN полностью → RU → KK. Сайт должен собираться и с частичным переводом: недостающий ключ падает на английский, не на пустую строку
- Не переводятся: IBM Quantum, Qiskit, Nazarbayev University, имена людей

## 10. Движение

Бюджет — четыре вида, больше не вводить:

1. Декрипшн заголовка hero (только там)
2. Reveal секций: сдвиг 12px + прозрачность, 400 мс, ease-out, через IntersectionObserver, один раз
3. Ховер: подчёркивание слева направо, 150 мс
4. Readout: рост полос и отсчёт чисел при появлении

Никакого параллакса, bounce, каруселей, курсор-эффектов. `prefers-reduced-motion` отключает всё и показывает финальные состояния.
